Версия 0.2 (15-08-2026):
- полностью переработана система хранения параметров векторных слоев, что обеспечило сокращение размера архива модуля (теперь векторные слои представлены тематическими наборами);
- добавлена возможность выполнять синхронизацию тематических наборов с удаленным репозиторием; теперь эталонный файл с параметрами векторных слоев хранится в удаленном репозитории, при обновлении/изменении данного файла можно выполнить синхронизацию непосредственно из модуля, при этом обновление самого модуля в данном случае не требуется.

Версия 0.1c (03-05-2026):
- функционал по формированию электронного документа в составе слоя FormedLand дополнен возможностью подготовки внесения изменений в проект межевания территории.

Версия 0.1b (26-04-2026):
- функционал по формированию электронного документа в составе слоя FormedLand дополнен возможностью записи информации о границах территории, в отношении которой утвержден проект межевания.

Версия 0.1a (19-04-2026):
- для слоя FormedLand из состава библиотеки gisogd-layer-library добавлен дополнительный функционал по формированию электронного документа, воспроизводящего сведения об утвержденном проекте межевания территории (в части границ образуемых земельных участков), в соответствии с XML-схемой interact_entry_boundaries_v02.
