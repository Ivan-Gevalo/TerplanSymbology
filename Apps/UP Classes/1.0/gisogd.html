Справочник "ГИСОГД"

Интерактивный справочник, воспроизводящий описание классов векторной модели, представленных в приказе Министерства строительства и жилищно-коммунального хозяйства Российской Федерации от 06.08.2020 № 433/пр. Для каждого класса объектов приведен набор атрибутов с указанием кодового наименования, описания, признака обязательности и типа данных. Для ряда атрибутов имеется активная ссылка для просмотра множества допустимых значений.
