Справочник Градостроителя

Web приложение, объединяющее различные интерактивные справочники, используемые в сфере градостроительства. В целом приложение может работать автономно: активное подключение к сети "Интернет" не требуется (за исключением некоторых случаев, когда необходимо перейти по активной ссылке в справочнике на сторонний ресурс).
