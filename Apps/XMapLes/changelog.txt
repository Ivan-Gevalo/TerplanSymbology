Версия 0.2.1 (21-11-2026):
- структура формируемых XML-документов приведена в соответствие с XML-схемой, размещенной на официальном сайте Федеральной государственной информационной системы территориального планирования в разделе "Методические материалы";
- в связи с изменением набора элементов, опредленных обновленной XML-схемой, переработана форма редактирования информации об объектах;
- произведена небольшая доработка программного кода для обеспечения обратной совместимости с файлами проектов, созданных в более ранних версиях приложения;
- выполнены чистка кода и удаление неиспользуемых ресурсов;
- исправлено некорректное поведение приложения при открытии файлов проектов, связанное с отсутствием пиктограмм (иконок) рядом с наименованием объектов.

Версия 0.2 (04-11-2026):
- изменена структура формируемых XML-документов с учетом примеров, предоставленных службой технической поддержки сайта ФГИС ТП (для всех классов объектов добавлен атрибут GLOBALID - идентификатор объекта, ZNP_TYPE - значение показателя, изменено целевое пространство имен и используемые префиксы для ряда элементов);
- при добавлении новых объектов в проект для большинства видов объектов добавлено отображение пиктограммы для более удобного визуального восприятия перечня объектов;
- небольшие косметические изменения (переработана главная форма приложения, обновлены иконки некоторых форм и пунктов меню).

Версия 0.1 (02-11-2025):
- исправлена ошибка создания объектов из состава классов "Объекты электроснабжения", "Объекты связи, общественного питания, торговли и бытового обслуживания";
- добавлено изменение цвета текста для отображения наименования классов объектов в составе проекта нормативов градостроительного проектирования (позиции, не содержащие объектов, отображаются светло-серым цветом, позиции с вложенными объектами - черным);
- при закрытии окна проекта нормативов градостроительного проектирования сообщение о сохранении проекта отображается только при внесении изменений в проект (переименование проекта, добавление, удаление или изменение объектов нормирования);
- небольшие косметические изменения (добавлены уникальные иконки для некоторых пунктов меню и диалоговых окон).
